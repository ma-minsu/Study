# 성경 인물 목록: 시대 구분 검토

## 적용 기준

- 사용자가 요청한 대로 여호와, 예수, 천사를 먼저 표시합니다. 이 세 항목은 인간 인물의 출생 순서로 비교하지 않습니다. 천사는 한 명의 인물이 아닌 범주입니다.
- 나머지 항목은 아래 출처를 참고해 성경 사건과 활동 시기별로 정리합니다. 같은 시대의 개인별 출생 순서는 알려지지 않은 경우가 많아 확정하지 않습니다.
- 현재 100개는 연구를 시작하기 위한 항목이며, 공식적인 ‘가장 유명한 100인’의 객관적 순위는 아닙니다. 동일 인물 여부·각 인물의 정밀한 생애 연대와 성구를 100건 모두 독립적으로 확정한 목록도 아닙니다.
- 사용자 추가 인물은 선택한 시대의 마지막에 표시되므로 같은 시대 안의 위치를 자동으로 추정하지 않습니다.

## 이번에 확인한 순서

- **유다와 요셉:** 유다는 야곱의 아들로 요셉보다 먼저 태어났으므로 요셉 앞에 둡니다. 창세기 29:35; 30:22–24.
- **스가랴:** 귀환 후 성전 재건을 격려한 스가랴를 에스더·에스라·느헤미야의 주요 활동보다 앞에 둡니다. [스가랴와 에스라 시대의 사건](https://wol.jw.org/ko/wol/d/r8/lp-ko/2023646) 참조. 이는 생애 전체에 대한 정확한 출생 순서를 뜻하지 않습니다.
- **예수의 가족과 침례자 요한:** 요셉과 마리아를 침례자 요한의 출생보다 앞에 표시합니다. 공식 연대표의 요셉·마리아 연대는 대략적입니다.
- **재판관 시대:** 나오미, 룻, 드보라, 기드온, 삼손의 생애가 놓이는 범위는 넓으며 개인별 연대가 불확실하므로, 표시 순서를 정밀한 출생 순서로 해석하지 않습니다.
- **왕국·유배·1세기:** 서로 겹치는 생애와 활동 기간을 고려해 단일 왕국/분열 왕국, 바빌론 유배/귀환 이후, 예수의 지상 생애 무렵/초기 회중으로 나누었습니다. 예언자와 왕의 모든 세부 순서를 검증한 것은 아닙니다.
- **동명이인:** 목록의 마리아는 예수의 어머니, ‘마리아 (마르다의 자매)’는 나사로의 누이로 구분합니다. 예수의 양아버지 요셉과 사도 야고보·요한도 괄호로 구분합니다. 다니엘의 세 친구는 바빌론식 이름으로 기재합니다.
