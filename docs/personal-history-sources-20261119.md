# 개인 연구 역사 목록: 연대 참고 자료

기본 목록의 연대는 여호와의 증인 출판물에서 사용하는 성경 연대기를 기준으로 한다. 고대 연대는 다른 역사학적 견해와 차이가 있을 수 있다. 출생, 통치 시작, 사건 발생 등 연도가 가리키는 기준은 항목에 표시한다. 정확한 시기를 확인하지 못한 항목에는 임의의 연도를 넣지 않는다.

- [연대 계산](https://wol.jw.org/ko/wol/d/r8/lp-ko/1200000970)
- [노아 시대의 홍수](https://wol.jw.org/ko/wol/d/r8/lp-ko/1997163)
- [여호사밧](https://wol.jw.org/ko/wol/d/r8/lp-ko/1999042)
- [예루살렘 성전](https://wol.jw.org/ko/wol/d/r8/lp-ko/2002841)
- [예수의 생애](https://wol.jw.org/ko/wol/d/r8/lp-ko/1101990129)

사용자가 추가하거나 변경한 항목의 시기는 사용자가 직접 정한다.
