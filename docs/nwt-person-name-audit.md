# 인물 이름 대조: 신세계역

기본 목록 100개 항목의 이름을 한국어 「신세계역 성경」 본문과 대조했습니다. 아래 성구는 이름 표기와 해당 인물을 확인하기 위한 근거입니다. 연대나 인물 선정의 적절성을 전부 검증했다는 뜻은 아닙니다. 천사는 개별 인명이 아닌 범주입니다. 괄호 속 설명은 동명이인을 구분하기 위한 사이트의 표현입니다.

- 카인의 기존 저장 식별자 `가인`과 침례자 요한의 아버지 스가랴의 기존 식별자 `사가랴`는 기존 기록 및 링크를 위해 유지합니다.
- 두 스가랴는 서로 다른 항목입니다. 각 본문은 예언자와 침례자 요한의 아버지를 각각 가리킵니다.
